# Таблица 19 – Структура проекта Django

| Каталог/файл | Назначение |
|---|---|
| users | Приложение для работы с пользователями и аутентификацией |
| shop | Приложение для управления каталогом товаров |
| orders | Приложение для работы с корзиной и заказами |
| serializers.py | Сериализация и валидация данных |
| views.py | Обработка запросов API |
| models.py | Описание моделей данных |
| urls.py | Маршрутизация запросов |

---

# Таблица 20 – Основные модели предметной области

| Модель | Назначение |
|---|---|
| User | Хранение данных пользователей и ролей |
| Category | Хранение категорий товаров |
| Product | Хранение информации о товарах |
| Cart | Хранение корзины пользователя |
| CartItem | Хранение товаров, добавленных в корзину |
| Order | Хранение оформленных заказов |
| OrderItem | Хранение товаров, входящих в заказ |

---

# Таблица 21 – Использование возможностей ORM Django

| Возможность ORM | Использование в проекте |
|---|---|
| Создание объектов | Создание пользователей, товаров и заказов |
| Получение данных | Получение каталога товаров и списка заказов |
| Изменение данных | Обновление информации о товарах и заказах |
| Удаление данных | Удаление товаров администратором |
| Связи между моделями | Реализация связей между пользователями, товарами, корзинами и заказами |

---

# Таблица 22 – Компоненты слоя управления (ViewSet и Serializer)

| Компонент | Назначение |
|---|---|
| ProductViewSet | Обработка запросов к товарам |
| CategoryViewSet | Управление категориями |
| OrderViewSet | Управление заказами |
| ProductSerializer | Валидация и преобразование данных товаров |
| CategorySerializer | Валидация данных категорий |
| OrderSerializer | Валидация данных заказов |
