# Таблица 41 – Инструкция по установке компонентов системы

| Компонент | Действие |
|---|---|
| Python | Установить Python 3.14 или выше |
| Node.js | Установить Node.js 20 или выше |
| PostgreSQL | Установить PostgreSQL 16 или выше |
| Backend | Выполнить установку зависимостей из requirements.txt |
| Frontend | Выполнить установку зависимостей через npm install |
