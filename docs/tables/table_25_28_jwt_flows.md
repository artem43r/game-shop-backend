# Таблица 25 – Стандартные HTTP-коды ответов API

| Код | Статус | Описание |
|---|---|---|
| 200 | OK | Успешное выполнение запроса (GET, PUT, PATCH) |
| 201 | Created | Ресурс успешно создан (POST) |
| 204 | No Content | Ресурс успешно удалён (DELETE) |
| 400 | Bad Request | Ошибка валидации данных. Тело ответа содержит описание ошибок по полям |
| 401 | Unauthorized | Отсутствует или недействителен JWT-токен. Клиент должен выполнить refresh или повторную авторизацию |
| 403 | Forbidden | Недостаточно прав (например, не-администратор пытается изменить товар) |
| 404 | Not Found | Запрашиваемый ресурс не найден |

# Таблица 26 – Поток получения JWT-токенов

| Шаг | Участник | Действие | Результат |
|---|---|---|---|
| 1 | Пользователь → React SPA | Вводит username и password на странице /login | Данные формы готовы к отправке |
| 2 | React SPA → Django API | POST /api/auth/login/ с телом {username, password} | HTTP-запрос отправлен |
| 3 | Django API | SimpleJWT проверяет учётные данные, генерирует пару токенов | Токены созданы |
| 4 | Django API → React SPA | Ответ 200: {access: '...', refresh: '...'} | Клиент получил токены |
| 5 | React SPA | Сохраняет access и refresh токены в localStorage | Пользователь авторизован |

# Таблица 27 – Поток выполнения авторизованного запроса

| Шаг | Участник | Действие | Результат |
|---|---|---|---|
| 1 | React SPA | Axios interceptor автоматически добавляет заголовок Authorization: Bearer <access_token> к запросу | Запрос содержит токен |
| 2 | React SPA → Django API | Отправляет GET/POST запрос с заголовком Authorization | Запрос принят сервером |
| 3 | Django API | JWTAuthentication проверяет подпись и срок действия токена | Токен валиден — запрос обработан |
| 4 | Django API → React SPA | Возвращает запрошенные данные (HTTP 200) | Данные отображены пользователю |

# Таблица 28 – Поток обновления токена

| Шаг | Участник | Действие | Результат |
|---|---|---|---|
| 1 | Django API → React SPA | Любой запрос возвращает HTTP 401 Unauthorized (access-токен истёк) | Interceptor перехватил ошибку |
| 2 | React SPA (Axios interceptor) | Автоматически отправляет POST /api/auth/token/refresh/ с {refresh} из localStorage | Запрос на обновление отправлен |
| 3 | Django API | SimpleJWT проверяет refresh-токен, генерирует новый access-токен | Новый access создан |
| 4 | Django API → React SPA | Ответ 200: {access: '<новый_токен>'} | Клиент обновил access в AuthContext |
| 5 | React SPA | Повторно выполняет исходный запрос с новым access-токеном | Пользователь не замечает прерывания сессии |
| 6* | React SPA | Если refresh тоже истёк — очищает AuthContext, перенаправляет на /login | Пользователь выходит из системы |
