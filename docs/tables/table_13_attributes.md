# Таблица 13 – Атрибуты сущностей предметной области

| Сущность | Атрибут | Описание | Ограничения |
| --- | --- | --- | --- |
| User | id | Уникальный идентификатор | PK, автоинкремент |
|  | username | Логин пользователя | UNIQUE, NOT NULL |
|  | email | Адрес электронной почты | UNIQUE, NOT NULL |
|  | password | Хеш пароля | NOT NULL |
|  | is_staff | Признак администратора | default=False |
|  | date_joined | Дата регистрации | NOT NULL |
| Category | id | Уникальный идентификатор | PK |
|  | name | Название категории | NOT NULL |
|  | description | Описание категории | NULL |
| Product | id | Уникальный идентификатор | PK |
|  | title | Название товара | NOT NULL |
|  | description | Описание товара | NULL |
|  | price | Стоимость товара | > 0 |
|  | currency_amount | Количество игровой валюты | > 0 |
|  | is_active | Доступность товара | default=True |
| Cart | id | Уникальный идентификатор | PK |
|  | created_at | Дата создания корзины | NOT NULL |
|  | updated_at | Дата изменения корзины | NOT NULL |
| CartItem | id | Уникальный идентификатор | PK |
|  | quantity | Количество товара | ≥ 1 |
| Order | id | Уникальный идентификатор | PK |
|  | status | Статус заказа | Новый / В обработке / Выполнен / Отменён |
|  | total_price | Итоговая стоимость | > 0 |
|  | created_at | Дата создания заказа | NOT NULL |
| OrderItem | id | Уникальный идентификатор | PK |
|  | quantity | Количество товара | ≥ 1 |
|  | price | Цена на момент заказа | > 0 |
