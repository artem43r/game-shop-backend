# Таблица 16 – Описание слоёв и их ответственности

| Слой | Технология | Ответственность |
|---|---|---|
| Представление | React SPA | Отображение интерфейса |
| API | Django REST Framework | Обработка HTTP-запросов |
| Бизнес-логика | Django | Реализация логики приложения |
| Доступ к данным | Django ORM | Работа с БД |
| Хранение данных | PostgreSQL | Хранение информации |

# Таблица 18 – Использование архитектурных паттернов

| Паттерн | Использование в проекте | Назначение |
|---|---|---|
| ViewSet | ProductViewSet, OrderViewSet | Обработка CRUD-операций через REST API |
| Serializer | ProductSerializer, OrderSerializer | Валидация и преобразование данных между JSON и объектами модели |
| React Hooks | useState, useEffect | Управление состоянием компонентов и выполнение побочных действий |
| Context API | AuthContext | Хранение данных авторизации и JWT-токенов на стороне клиента |
