# Таблица 5 – Сравнение подходов к разработке веб-приложения

| Критерий | Индивидуальная разработка (Django REST + React) | Платформенные решения (Tilda, Shopify) | Интеграционные решения (CRM + кастомный frontend) |
|---|---|---|---|
| Архитектура системы | Клиент-серверная (REST API + SPA) | Монолитная | Гибридная |
| Гибкость бизнес-логики | Полная | Ограниченная | Частичная |
| Уровень безопасности | Высокий (контроль на backend) | Средний | Зависит от CRM |
| Масштабируемость | Высокая | Ограниченная | Средняя |
| Производительность интерфейса | Высокая (SPA) | Средняя | Средняя |
| Интеграция с внешними сервисами | Полная (API-first) | Ограниченная | Частичная |
| Контроль над данными | Полный | Ограниченный | Частичный |
